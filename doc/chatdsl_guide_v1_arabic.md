# دليل ChatDSL الشامل

## نظرة عامة

إن ChatDSL (لغة المجال الخاصة بالدردشة) هي لغة برمجية قوية مصممة لأتمتة التفاعلات مع نماذج اللغات الكبيرة (LLMs). يقدم هذا الدليل مرجعاً كاملاً للعمل مع ChatDSL، بما في ذلك الميزات، والبرامج التعليمية، والإرشادات التفصيلية، ومرجعاً شاملاً للكلمات المفتاحية.

> *آخر تحديث: 1 سبتمبر 2026*
>
> *الإصدار: 1.0*
>
> *متوافق مع Chatybot v0.8.0+*

# الميزات

## القدرات الأساسية

### 1. دعم لغات متعددة
تدعم لغة ChatDSL 6 لغات مع دعم كامل للأسماء المستعارة للأوامر:
- **الإنجليزية (EN)** - اللغة الأساسية
- **الإسبانية (ES)** - الترجمة الإسبانية لجميع الأوامر
- **الفرنسية (FR)** - الترجمة الفرنسية لجميع الأوامر
- **الصينية (ZH)** - الترجمة الصينية لجميع الأوامر
- **الإيطالية (IT)** - الترجمة الإيطالية لجميع الأوامر
- **العربية (AR)** - الترجمة العربية لجميع الأوامر

### 2. ميزات البرمجة
- **نظام المتغيرات**: متغيرات معرفة على مستوى السيناريو باستخدام صيغة `${الاسم}`
- **المنطق الشرطي**: جمل شرطية `if` باستخدام العمليات `==` و `!=` و `not` (مع استخدام `then` لتنفيذ الأمر)
- **إدارة الذاكرة المؤقتة**: الذاكرة المؤقتة الرئيسية و 5 مخازن ملفات للحفاظ على السياق
- **إدخال متعدد الأسطر**: كتابة أوامر برمجية معقدة تمتد لعدة أسطر
- **عمليات الملفات**: تحميل، عرض، مسح، وحفظ الملفات
- **بارامترات السيناريو**: بارامترات مخصصة `x` و `y` و `z` للسيناريوهات البرمجية
- **الماكرو**: قوالب أوامر قابلة لإعادة الاستخدام مبنية على قواعد PEG الخاصة بـ Parsley
- **مفتاح البحث في السجل**: استخدام المشغل `!` للبحث في سجل الأوامر

### 3. تكامل نماذج اللغة الكبيرة (LLM)
- **إدارة النماذج**: التبديل بين أكثر من 20 نموذجاً تم تكوينها عبر 8 موفرين للخدمة
- **توجيهات النظام**: تعيين القواعد السلوكية الأساسية للنموذج
- **درجة الحرارة (Temperature)**: التحكم في درجة العشوائية من `0.0-2.0` للردود
- **الحد الأقصى للتوكنز**: التحكم في طول النص المولد
- **التحكم في أخذ العينات**: `top_p` و `top_k` وعقوبة التكرار وعقوبة الحضور
- **التحكم في التفكير**: التحكم في أنماط التفكير والجهد وعرض التفكير
- **تحسينات خاصة بموفري الخدمة**: تهيئة الأداء لـ NVIDIA و Mistral و Google و OpenAI

### 4. الميزات المتقدمة
- **حلقات الأدوات**: تشغيل مستقل لحلقات عمل العميل الذكي باستدعاء الأدوات (محلياً و عبر بروتوكول MCP)
- **توليد الصور**: دعم موفري الخدمة OpenAI و Mistral و OpenRouter و Ollama
- **تكامل قاعدة البيانات**: تخزين متجه للبيانات عبر TinyDB مع ميزة إعادة التصنيف
- **نظام الملفات الشخصية (Profiles)**: ملفات `.chatdsl` كملفات تعريف للعمل المستمر
- **تكامل بروتوكول MCP**: دعم خادم بروتوكول سياق النموذج

### 5. التشخيص والمراقبة
- **مخرجات التتبع**: قياس التوكنز في الثانية (TPS) وحجم البيانات المرسلة وتصحيح الصور ومتابعة حلقات العمل
- **أوامر التصحيح**: عرض الردود الخام للنموذج واستخدام الذاكرة الافتراضية
- **التسجيل**: كتابة سجل المحادثة وتتبع الأخطاء في ملفات سجل
- **فحص الذاكرة المؤقتة**: فحص حالة الذاكرة والمتغيرات

# البرامج التعليمية

## الدرس 1: سير العمل الأساسي للترجمة

يوضح هذا الدرس كيفية ترجمة ملف بين لغات مختلفة باستخدام ChatDSL.

### المتطلبات الأساسية
- ملف نصي مصدر للترجمة (`english.txt`)
- مفاتيح الروابط البرمجية (API) مهيأة في الملف `~/.config/chatybot/chat_config.toml`

### دليل خطوة بخطوة

1. **تهيئة البارامترات**
   ```dsl
   # الاستخدام: /سيناريو translate.chatdsl x=english.txt y=spanish z=output.txt
   if ${x} != "" then حط source_file = ${x}
   if ${source_file} == "" then حط source_file = "english.txt"
   
   if ${y} != "" then حط target_lang = ${y}
   if ${target_lang} == "" then حط target_lang = "spanish"
   
   if ${z} != "" then حط output_file = ${z}
   if ${output_file} == "" then حط output_file = "output.txt"
   ```

2. **تحميل الملف المصدر**
   ```dsl
   /ملف ${source_file}
   ```

3. **تنفيذ الترجمة**
   ```dsl
   /ترديد "Translating to ${target_lang}..."
   
   /نموذج gemini_flash
   Translate ${target_lang}:
   
   /حفظ ${output_file}
   ```

4. **النتائج**
   - يتم إنشاء ملف جديد في المسار `${output_file}`
   - يتم حفظ الترجمة باللغة المستهدفة

### السيناريو الكامل

```dsl
# translate.chatdsl
# الاستخدام: /سيناريو translate.chatdsl x=english.txt y=spanish z=output.txt

# معالجة البارامترات
if ${x} != "" then حط source_file = ${x}
if ${source_file} == "" then حط source_file = "english.txt"

if ${y} != "" then حط target_lang = ${y}
if ${target_lang} == "" then حط target_lang = "spanish"

if ${z} != "" then حط output_file = ${z}
if ${output_file} == "" then حط output_file = "output.txt"

# تحميل المصدر
/ملف ${source_file}

# ترجمة
/ترديد "Translating to ${target_lang}..."

/نموذج gemini_flash
Translate ${target_lang}:

/حفظ ${output_file}

/ترديد "Translation saved to ${output_file}"
```

## الدرس 2: مقارنة الملفات باستخدام ChatDSL

تعلم كيفية مقارنة ملفين وتحديد الاختلافات الجوهرية بينهما.

### الاستخدام
```bash
chatybot
دردش --> /سيناريو compare_articles.chatdsl x=article1.txt y=article2.txt z=comparison.txt
```

### السيناريو الكامل

```dsl
# compare_articles.chatdsl
# الاستخدام: /سيناريو compare_articles.chatdsl x=article1.txt y=article2.txt z=comparison.txt

# معالجة البارامترات
if ${x} != "" then حط file1 = ${x}
if ${file1} == "" then حط file1 = "default1.txt"

if ${y} != "" then حط file2 = ${y}
if ${file2} == "" then حط file2 = "default2.txt"

if ${z} != "" then حط output = ${z}
if ${output} == "" then حط output = "comparison.txt"

# تحميل الملفات في مخازن الملفات
/مخزن_الملفات1 ${file1}
/مخزن_الملفات2 ${file2}

/ترديد "Comparing ${file1} and ${file2}"

# توليد المقارنة
/نظام "You are a precise text comparison expert."

/متعدد_الأسطر
Compare these two articles and identify:
1. Structural differences
2. Content differences
3. Style differences

Article A:
{filebank1}

Article B:
{filebank2}

Provide a detailed comparison.
;;
/متعدد_الأسطر

# حفظ النتيجة
/حفظ ${output}

/ترديد "Comparison saved to ${output}"
```

### المخرجات المتوقعة
سوف يقوم السيناريو بإنتاج تقرير مقارنة مفصل يشمل:
- **اختلافات هيكلية**: ترتيب الفقرات، العناوين، والتنسيق
- **اختلافات المحتوى**: الحقائق والأرقام والحجج الأساسية
- **اختلافات الأسلوب**: المفردات وبناء الجمل ونبرة الكتابة

## الدرس 3: تقييم النماذج المتعددة

تقييم استجابة نماذج الذكاء الاصطناعي المختلفة لنفس المدخلات (البرومبت).

### الاستخدام
```bash
chatybot
دردش --> /سيناريو evaluate.chatdsl x=prompt.txt y=output_dir
```

### السيناريو الكامل

```dsl
# evaluate.chatdsl
# الاستخدام: /سيناريو evaluate.chatdsl x=prompt_file y=output_dir

حط prompt_file = ${x}
حط output_dir = ${y}

# النموذج الأول - GPT-4
/ترديد "Processing with GPT-4..."
/نموذج openai_gpt4
/prompt ${prompt_file}
/حفظ ${output_dir}/gpt4_response.txt

# النموذج الثاني - Claude
/ترديد "Processing with Claude..."
/نموذج claude
/prompt ${prompt_file}
/حفظ ${output_dir}/claude_response.txt

# مقارنة الردود
/ترديد "Comparing models..."

/مخزن_الملفات1 ${output_dir}/gpt4_response.txt
/مخزن_الملفات2 ${output_dir}/claude_response.txt

/متعدد_الأسطر
Compare these two responses to the same prompt:

Model A (GPT-4):
{filebank1}

Model B (Claude):
{filebank2}

Which is better and why?
;;
/متعدد_الأسطر
/حفظ ${output_dir}/comparison.txt

/ترديد "Evaluation complete! Results in ${output_dir}"
```

### ملفات المخرجات
- `${output_dir}/gpt4_response.txt` - رد نموذج GPT-4
- `${output_dir}/claude_response.txt` - رد نموذج Claude
- `${output_dir}/comparison.txt` - مقارنة تفصيلية جنباً إلى جنب

# الإرشادات التفصيلية (HowTos)

## كيف: تهيئة إعدادات Chatybot

### موقع ملف التكوين
```bash
~/.config/chatybot/chat_config.toml    # ملف تكوين المستخدم (يلغي الإعدادات الافتراضية)
src/chatybot/chat_config.toml          # ملف تكوين الإعدادات الافتراضية المرفق بالبرنامج
```

### صيغة ملف التكوين (TOML)

```toml
# ============================================================================
# إعدادات توليد الصور
# ============================================================================

[image_generation]
default_dir = "~/chatybot_images"
default_size = "1024x1024"
default_quality = "standard"

# ============================================================================
# نماذج الدردشة المتاحة
# ============================================================================

[models.mistral_1]
name = "mistral-large-2512"
temperature = 0.7
top_k = 1
base_url = "https://api.mistral.ai/v1"
api_key = "MISTRAL_API_KEY"
image_generation = true
image_endpoint = "/images/generations"
vendor = "mistral"

[models.gemini_flash]
name = "gemini-2.5-flash"
temperature = 0.0
top_k = 1
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "GEMINI_API_KEY"
image_generation = true
vendor = "google"

[models.openai_gpt4]
name = "gpt-4o"
temperature = 0.1
top_k = 1
base_url = "https://api.openai.com/v1"
api_key = "OPENAI_API_KEY"
image_generation = true
vendor = "openai"

[models.ollama_llama3]
name = "llama3.2"
temperature = 0.7
top_k = 1
base_url = "http://localhost:11434/v1"
api_key = "OLLAMA"
```

### خصائص تكوين النماذج

| الخاصية | النوع | الوصف |
|-----------|------|-------------|
| `name` | نص (string) | اسم النموذج المعرف لدى واجهة API |
| `temperature` | عشري (float) | درجة العشوائية والاستجابة (0.0-2.0) |
| `top_k` | صحيح (integer) | عدد التوكنز في عينة Top-K |
| `base_url` | نص (string) | رابط خادم واجهة API الموفر للخدمة |
| `api_key` | نص (string) | اسم متغير البيئة الذي يحتوي على مفتاح API |
| `image_generation` | منطقي (boolean) | تفعيل ميزة توليد الصور للنموذج |
| `image_endpoint` | نص (string) | مسار رابط توليد الصور |
| `vendor` | نص (string) | اسم الشركة الموفرة للخدمة |

### موفرو الخدمة المدعومون

| موفر الخدمة | الوصف |
|-----------|-------------|
| `mistral` | خوادم شركة Mistral AI |
| `google` | منصة Google Generative AI |
| `openai` | خوادم شركة OpenAI |
| `openrouter` | واجهة OpenRouter المجمعة للنماذج |
| `nvidia` | واجهة غيمة NVIDIA NIM |
| `publicai` | خوادم منصة PublicAI |
| `bytez` | منصة Bytez للحوسبة |
| `ollama` | خادم Ollama المحلي على جهازك |

## كيف: معالجة الملفات كدفعة واحدة (Batch Process)

نظراً لأن لغة ChatDSL لا تحتوي على حلقات تكرار مدمجة، يمكنك معالجة عدة ملفات عن طريق كتابة نفس الخطوات لكل ملف يدوياً:

### قالب السيناريو البرمجي

```dsl
# batch.chatdsl
# الاستخدام: /سيناريو batch.chatdsl x=input_dir y=output_dir

حط input_dir = ${x}
حط output_dir = ${y}

# معالجة الملف الأول
حط file = "a.txt"
/ملف ${input_dir}/${file}
Analyze ${file}
/حفظ ${output_dir}/${file}_processed.txt

# معالجة الملف الثاني
حط file = "b.txt"
/ملف ${input_dir}/${file}
Analyze ${file}
/حفظ ${output_dir}/${file}_processed.txt

# معالجة الملف الثالث
حط file = "c.txt"
/ملف ${input_dir}/${file}
Analyze ${file}
/حفظ ${output_dir}/${file}_processed.txt
```

## كيف: تكوين حلقة استدعاء الأدوات للعميل الذكي

```dsl
# تفعيل هياكل الأدوات في التوجيهات
```

```dsl
/أداة حلقة 50 force
```

### فحص حالة الأدوات الحالية
```dsl
/أداة عرض
/أداة prompt
```

### الأدوات المتاحة للنظام

| الأداة | الوصف |
|-------------|-------------|
| `list_directory` | عرض محتويات دليل أو مجلد محدد |
| `read_file` | قراءة محتويات ملف نصي بالكامل |
| `find_files` | البحث عن ملفات مطابقة لنمط محدد |
| `run_command` | تشغيل أمر سطر أوامر النظام |
| `write_file` | كتابة محتوى أو الإضافة لملف على القرص |
| `change_dir` | تغيير مجلد العمل الحالي للبرنامج |
| `grep_search` | البحث عن نصوص محددة داخل الملفات |
| `replace_file_content` | استبدال نصوص محددة داخل ملف معين |

```dsl
# طلب توليد صورة بناءً على نص

# عرض قائمة الصور التي تم حفظها
/عرض_الصور

# عرض تفاصيل الصورة الحالية
/عرض_تفاصيل_الصورة
```

### توليد وحفظ صورة مباشرة
```dsl
# توليد وحفظ النتيجة في مسار محدد
/تخيل a cat playing with yarn
/saveimage images/cat_toy.jpg
```

### تحميل صورة في مخازن الصور لاستخدامها في الدردشة
```dsl
# تحميل ملف الصورة للدردشة متعددة الوسائط
/تحميل_صورة images/cat_toy.jpg imagebank1

# استخدامها في التوجيهات
Describe this image: {imagebank1}
```

### إدارة مخازن الصور
```dsl
# حفظ مباشر في المخزن
/مخزن_الصور1 path/to/image.jpg

# عرض محتويات المخزن الحالي
/مخزن_الصور1 show

# مسح مخزن الصور
/مخزن_الصور1 clear
```

## كيف: استخدام وتكامل قواعد البيانات المتجهة

### الاتصال بقاعدة البيانات والبحث
```dsl
# الاتصال بقاعدة البيانات أو إنشاؤها
/تحدد_قاعدة_البيانات knowledge_base

# بحث متجه عن نصوص معينة
/بحث_قاعدة_البيانات "machine learning algorithms 2024"

# جلب جميع النتائج إلى متغير
/loadvar ml_results ALL

# إضافة سياق البيانات إلى موجه المحادثة
/نظام "You are an AI expert with access to 2024 ML research."

Based on: ${ml_results}

What are the key developments in ML in 2024?

# حفظ المحادثة الحالية في قاعدة البيانات
/سجل_قاعدة_البيانات
```

### إعادة ترتيب نتائج البحث (Rerank)
```dsl
# تنفيذ بحث ثم إعادة ترتيب النتائج
/بحث_قاعدة_البيانات "climate change economics"
/إعادة_ترتيب

# جلب أفضل 5 نتائج بعد إعادة الترتيب
/loadvar ranked_results TOP5
```

### تحديد مصادر المستندات لإعادة الترتيب

| المصدر | الصيغة البرمجية | الوصف |
|--------|--------|-------------|
| قاعدة البيانات | `/مستندات db=<اسم قاعدة البيانات>` | قاعدة بيانات متجهة TinyDB |
| متغير برمجى | `/مستندات var=<اسم المتغير>` | متغير من متغيرات السيناريو |
| مخزن الملفات | `/مستندات filebank=<1-5>` | محتويات مخازن الملفات للبرنامج |
| مجلد على القرص | `/مستندات dir="<المسار>"` | قراءة جميع الملفات النصية في المجلد |

## كيف: إدارة الملفات الشخصية (Profiles)

### أوامر الملفات الشخصية

```dsl
# عرض الملفات الشخصية المتوفرة
/profile list

# تنشيط واستخدام ملف شخصي محدد
/profile use my_profile

# نسخ الجلسة الحالية كملف تعريف جديد
/profile clone new_profile

# حذف ملف تعريف محدد
/profile delete old_profile

# تصدير ملف شخصي لمجلد خارجي
/profile export my_profile export_path/

# استيراد ملف تعريف من مجلد خارجي
/profile import import_path/

# عرض حالة ومعلومات الملف الشخصي الحالي
/profile show

# تحرير الملف الشخصي الحالي في المحرر الرسومي
/profile edit
```

### مجلدات حفظ الملفات الشخصية
```bash
~/.config/chatybot/profiles/    # الملفات المخصصة للمستخدم
src/chatybot/profiles/          # الملفات الافتراضية المرفقة
```

# أفضل الممارسات

## إرشادات كتابة سيناريوهات ChatDSL

### 1. تسمية المتغيرات
- استخدم طريقة **snake_case** للتسمية المعبرة: `article_num` و `model_name`
- استخدم أحرفاً مفردة (`x` و `y` و `z`) فقط للبارامترات الخارجية الممررة للسيناريو
- استخدم الأحرف الكبيرة للإشارة للثوابت البرمجية

### 2. كتابة التعليقات
```dsl
# تعليق يغطي السطر بأكمله
حط var = "value"  # تعليق مضاف بجانب الكود

# فواصل وتسمية أجزاء الكود البرمجي
# ============================================
# قسم معالجة الترجمة
# ============================================
```

### 3. بنية السيناريو البرمجي المثالية
```dsl
# عنوان وتفاصيل الاستخدام
# السيناريو: وصف سريع للوظيفة
# الاستخدام: /سيناريو script.chatdsl [متغيرات ممررة]

# معالجة وتأمين قيم البارامترات الخارجية
if ${x} != "" then حط param1 = ${x}
if ${param1} == "" then حط param1 = "default"

# إعداد خيارات التشغيل
حط base_dir = "output"
/نموذج gemini_flash

# منطق العمل الأساسي
/ملف input.txt
process this...
/حفظ output.txt

# تنظيف الذاكرة المؤقتة (اختياري)
/مسح_الملف
/ترديد "Done"
```

### 4. أنماط كتابة شائعة ومفيدة

#### تعيين قيم افتراضية بديلة للمتغيرات
```dsl
if ${x} != "" then حط var = ${x}
if ${var} == "" then حط var = "default"
```

#### التبديل الشرطي بين نماذج الذكاء الاصطناعي
```dsl
if ${fast} then /نموذج gemini_flash
if not ${fast} then /نموذج openai_gpt4
```

## تصحيح واستكشاف الأخطاء وإصلاحها

### مشاكل شائعة وحلولها المقترحة

| المشكلة | الحل المقترح |
|----------|----------|
| المتغير لا يتم استبدال قيمته | تأكد من استخدام الصيغة الدقيقة `${الاسم}` (دون ترك مسافات) |
| رسالة تفيد بعدم وجود الملف | استخدم أمر `/ترديد` لطباعة قيم المتغير وفحص مسار الملف الفعلي |
| وضع النص الطويل لا ينتهي | تأكد من وضع علامة `;;` بمفردها على سطر مستقل، ثم كتابة `/متعدد_الأسطر` |
| خطأ عند وضع نصوص بها مسافات | استخدم علامات اقتباس مزدوجة عند تحديد القيمة: `حط var = "قيمة بها مسافات"` |
| خطأ ناتج عن استخدام الخط المائل الخلفي | غير مسموح بالرموز المائلة الخلفية في القيم - استخدم الخط المائل الأمامي `/` للمسارات |
| خطأ يفيد بعدم التعرف على الأمر | تأكد من وضع الخط المائل الأمامي `/` في بداية الأمر البرمجي وتأكد من الهجاء |

## سيناريوهات توضيحية جاهزة للتشغيل

تحقق من مجلد `dsl_test/` المرفق مع البرنامج لتشغيل وتحليل ملفات جاهزة:
- `translate.chatdsl` - سيناريو لأتمتة سير عمل الترجمة بين اللغات
- `compare.chatdsl` - مقارنة ملفين نصيين واستخراج الاختلافات
- `evaluate.chatdsl` - مقارنة جودة ردود عدة نماذج لنفس الطلب
- `batch.chatdsl` - معالجة مجموعة من الملفات دفعة واحدة
